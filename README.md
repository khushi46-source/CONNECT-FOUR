# Connect Four Game

A simple **Connect Four** game built with **Python** that runs in the terminal. Two players take turns dropping their pieces into a 6×7 grid, and the first player to connect four pieces horizontally, vertically, or diagonally wins the game.

## Features

* Two-player gameplay
* 6×7 game board
* Automatic piece dropping
* Horizontal, vertical, and diagonal win detection
* Input validation for invalid or full columns
* Easy-to-read terminal interface

## Technologies Used

* Python 3
* Visual Studio Code

## How to Run

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project folder:

   ```bash
   cd ConnectFourGame
   ```

3. Run the game:

   ```bash
   python connect_four.py
   ```

## How to Play

* Player **X** starts the game.
* Enter a column number from **0 to 6** to drop your piece.
* Pieces automatically fall to the lowest available position.
* The first player to connect **4** pieces in a row (horizontal, vertical, or diagonal) wins.
